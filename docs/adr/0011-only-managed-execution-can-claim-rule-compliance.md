# Only Managed Execution Can Claim That Rules Were Applied

Teams do not have to place every AI coding activity in the console, but work that requires governance, tracking, or acceptance must be created, authorized, and started or resumed through the work control layer. Only this managed execution can check rules before execution, preserve checkpoints during execution, and review evidence before acceptance. A managed start is not comprehensive proof of compliance. For each rule, the console must use its actual ability to block, detect, collect evidence, or obtain human confirmation to report the result as verified, partially verified, or indeterminate. Work started outside the control layer may be discovered and displayed, but it must be marked as unmanaged execution.

## 中文

# 只有受控执行才能声明规则已经落实

团队不必把所有 AI 编码活动都放入控制台，但需要治理、追踪或验收的工作必须通过工作控制层创建、授权并启动或恢复。只有这种受控执行才能在执行前检查规则、在过程中留下检查点并在验收前核对证据。受控启动本身不构成全面合规证明；控制台必须根据各条规则实际具备的阻止、检测、证据或人工确认能力，显示已验证、部分验证或无法判断。绕过控制层启动的工作可以被发现和展示，但必须标记为非受控执行。
