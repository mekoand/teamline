# The Personal Edition Is a Complete Local Work Control Product

The local personal edition is not a quota monitor, a team client, or a deliberately incomplete trial. Its complete product boundary includes local goals, plan confirmation, personal authorization and rules, resource plans, cross-project execution overview, checkpoints, pause and recovery, recoverable tool switching, execution maps, and acceptance evidence. “Complete” does not mean the first release must support multiple tools and every view. The first build validates the individual loop with one repository, one tool, and a local web interface, then expands personal capabilities gradually. All data stays on the device by default and no account is required. Moving a personal goal into a team creates an immutable baseline, with earlier history marked as unmanaged. Paid team capabilities add shared rules, multi-person permissions, cross-person handoff, team approval, and centralized audit.

## 中文

# 个人版是一套完整的本地工作控制产品

个人本地版不是额度监控器、团队客户端或功能残缺的试用版。完整产品边界包括本地目标、计划确认、个人授权与规则、资源方案、跨项目运行总览、检查点、暂停与恢复、可恢复的工具切换、执行图和验收证据，但“完整”不表示这些能力必须在第一个版本同时支持多个工具和全部界面。第一个建设阶段只用一个仓库、一种工具和本地网页验证单人闭环，再逐步扩大个人能力。所有数据默认保留在本机，不要求注册账号；个人目标转入团队时生成不可变基线，基线前历史保持非受控标记。团队付费能力增加共享规则、多人权限、跨人交接、团队审批和集中审计。
