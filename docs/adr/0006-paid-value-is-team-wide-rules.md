# Paid Value Comes from Team-Wide Rules

The commercial promise of the team console is not another shared board. It is the ability to advance more AI coding work in parallel and reliably under shared rules. Rules can apply across members, projects, tools, and execution environments. Work state, resources, and usage are inputs to rule decisions; the paid value is that constraints remain in effect and produce reviewable, traceable results.

---

## 中文

# 付费价值是执行团队范围内的共同规则

团队控制台的商业承诺不是提供另一张共享看板，而是让团队在统一规则下可靠地并行推进更多 AI 编码工作。规则可以跨成员、项目、工具和执行环境生效；工作状态、资源和用量是规则判断的输入，真正的付费价值在于约束能够持续执行并留下可验收、可追溯的结果。
