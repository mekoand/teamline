# Each Information Type Has One Authoritative Source

The console does not copy and bidirectionally synchronize all information from GitHub, Linear, Jira, Notion, or Git. External systems continue to own requirements, documents, code, identity, and actual vendor usage. The team control plane owns published team rules, team budgets and resource reservations, and the plans, authorization, execution state, exceptions, and acceptance records of team goals. Personal rules and goals are owned by the local personal console by default. External information enters through stable references and version records captured when a plan is confirmed. Full-text snapshots require explicit team opt-in, and the console only writes progress and evidence summaries back to the source system.

## 中文

# 每类信息只有一个权威来源

控制台不复制并双向同步 GitHub、Linear、Jira、Notion 或 Git 中的完整信息。外部系统继续拥有需求、文档、代码、身份和供应商实际用量；团队控制面拥有已发布团队规则、团队预算与资源预留，以及团队目标的计划、授权、执行状态、异常和验收记录；个人规则与个人目标默认由个人本地控制台拥有。外部信息通过稳定引用和计划确认时的版本记录接入，正文快照需要团队明确开启，控制台只向原系统回写进度与证据摘要。
