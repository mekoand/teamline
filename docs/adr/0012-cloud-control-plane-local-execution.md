# The Team Product Uses a Cloud Control Plane and Local Execution

The team console stores goal state, plans, rule versions, team budgets, authorizations and exceptions, check results, and acceptance summaries in the cloud so members can share control state. AI coding tools continue to run on developer machines or in team-owned environments. Source code, repository credentials, model sessions, and complete execution records are not uploaded to this product's control plane by default; data handling between each existing tool and its vendor remains governed by that tool's settings. The first version does not provide hosted agents, cloud development environments, or default code uploads, preventing the work control layer from expanding into another cloud IDE.

## 中文

# 团队版采用云端控制面与本地执行

团队控制台在云端保存目标状态、计划、规则版本、团队预算、授权与例外、检查结果和验收摘要，以便成员共享控制状态。AI 编码工具继续在开发者电脑或团队自有环境中运行，源代码、仓库凭据、模型会话和完整执行记录默认不上传至本产品控制面；现有工具与其供应商之间的数据处理仍由对应工具设置决定。第一版不提供托管 Agent、云端开发环境或默认代码上传，避免工作控制层扩张为另一套云端 IDE。
