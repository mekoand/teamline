# The Long-Term Vision Is an AI-Native Team Operating System

The current product hypothesis remains a work control layer for small AI coding teams, and the first MVP validates only the managed goal loop and minimum resource capabilities. The long-term product grows along the same line into an AI-native team operating system. Work control remains the core while resource management expands to tool subscriptions, model budgets, and execution environments. Real work produces reusable rule templates, best practices, onboarding paths, and training. The product also provides views of return on investment, delivery quality, risk, exceptions, and audit. It does not replace code repositories, requirements systems, finance systems, knowledge bases, or general learning platforms.

## 中文

# 长期愿景是 AI-native 团队运行系统

当前产品假设仍然是小型 AI 编码团队的工作控制层，首个 MVP 只验证受控目标闭环与最小资源能力。长期产品沿这条主线扩展为 AI-native 团队运行系统：以工作控制为核心，逐步增加工具订阅、模型预算与执行环境等资源经营能力，基于真实工作沉淀规则模板、最佳实践、入职路径与培训，并提供投入产出、交付质量、风险、例外和审计视图。产品不替代代码仓库、需求系统、财务系统、知识库或通用学习平台。
