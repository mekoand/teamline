# 工具与预算进入委托计划而不只是被监控

每项工作委托在计划确认时同时确定资源方案，包括允许的工具、模型、Provider 引用与执行环境，首选和备用顺序，预算、额度与运行时间，以及需要重新批准的变化。个人内核 v0 只验证单项委托约束：记录 Codex、可识别的模型、最长运行时间和可选用量或费用提醒阈值；本地运行时间可以到点暂停，Token、费用和额度只有在实时、可归因并达到规则要求时才能触发已授权动作，否则明确标为仅提醒。个人内核 v0 不接 CC Switch，不做订阅切换、跨工具分配或资源总览。个人 Alpha 再验证多个并行委托与多个 Provider 的资源总览和分配，团队付费 MVP 才增加共享预算的分配、预留与集中审计；产品不代购或转售模型额度，也不集中托管供应商账号。
