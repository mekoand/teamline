# The Core Metric Is Reliable Review-Ready Goals per Owner per Week

The product does not use quota utilization, run time, team activity, or agent execution count as its core measure of value. The core metric is how many managed goals each owner advances reliably to review each week. A counted goal must have a confirmed plan, an applied effective rule set, recovery checkpoints, and acceptance evidence. Rework, rejection, and unplanned manual coordination are tracked separately as guardrail metrics so throughput cannot hide declining quality.

## 中文

# 核心指标是每名负责人每周可靠进入待验收的目标数

产品不以额度利用率、运行时长、团队活跃人数或 Agent 执行次数衡量核心价值。核心指标是每名目标负责人每周将多少受控执行可靠推进到待验收状态。计入的目标必须完成计划确认、应用生效规则集、保留恢复检查点并提供验收证据；返工、退回和计划外人工协调作为约束指标单独观察，避免用吞吐量掩盖质量下降。
