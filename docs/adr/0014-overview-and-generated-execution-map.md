# The Primary Product Views Are an Overview and Generated Execution Map

The team home page uses an execution overview to present goals that need attention, are running, are blocked, or await acceptance, helping members identify the next item that requires human involvement. Each goal has an execution map generated automatically from its confirmed plan and checkpoints. Simple work appears as a timeline; only complex work expands into a node graph. Users do not manually draw workflows, and the first version does not provide an infinite canvas or general workflow builder. Spatial presentation expresses real execution state rather than adding modeling work.

## 中文

# 主产品形态是运行总览与自动执行图

团队首页使用运行总览呈现需要处理、运行中、受阻和待验收的工作目标，帮助成员立即识别下一项需要人介入的工作。单个目标使用系统根据已确认计划和检查点自动生成的执行图，简单工作呈现为时间线，复杂工作才展开为节点图。第一版不要求用户手工绘制流程，也不提供无限画布或通用工作流编排；视觉空间感用于表达真实运行状态，而不是增加建模工作。
