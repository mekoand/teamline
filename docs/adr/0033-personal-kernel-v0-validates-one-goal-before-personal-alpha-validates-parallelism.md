# Personal Kernel v0 Validates One Goal Before Personal Alpha Validates Parallelism

Personal kernel v0 runs only one active goal to validate plan confirmation, managed start, checkpoints, interruption recovery, and acceptance evidence with minimum scope. This is an implementation-slice limit and must not enter the platform-independent domain model. Personal Alpha must support at least two goals running in parallel in their own execution workspaces and under separate execution leases to validate the core value of controlled parallelism. The product does not hard-code a universal concurrency number; the actual limit follows local resources and user settings.

## 中文

# 个人内核 v0 先验证单目标而个人 Alpha 必须验证并行

个人内核 v0 只运行一个活动目标，以最小范围验证计划确认、受控启动、检查点、中断恢复和验收证据；这只是工程切片限制，不能进入平台无关的领域模型。个人 Alpha 必须支持至少两个目标在各自独占的执行工作区和执行租约下并行运行，才能验证“可控并行”的核心价值。产品不写死统一并发数，实际上限由本机资源和用户设置决定。
