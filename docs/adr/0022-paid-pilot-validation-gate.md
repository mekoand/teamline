# 用五支团队的付费试点验证产品假设

团队试点开始前冻结复杂度分层，但不把复杂度作为进入受控执行的产品门槛。所有具有明确边界、会产生代码变更并有验收方式的工作都可以形成委托；预计至少两小时或两个执行阶段只用于预先区分长程工作与短工作，并分别观察效果。五支团队先记录两周同口径基线，再实际支付 99 美元使用四周。产品假设成立需要同时满足：至少三支团队把一半以上符合目标场景的长程工作放进受控执行；按复杂度分层后每名负责人每周可靠进入待验收的委托数提高至少 30%；三个工作日内的一次验收通过率不低于基线，重大返工率、计划外协调时间和规则例外率按委托归一化后不明显恶化；至少三支团队在试点结束后再次实际支付 99 美元续费。试点结束后不得调整分层或通过任意拆小委托提高结果。
