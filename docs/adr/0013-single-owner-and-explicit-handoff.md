# Each Goal Has One Owner and Explicit Handoffs

Every work goal always has one current owner responsible for its boundary, plan confirmation, authorization, exception handling, and entry into review. Execution may move across members, tools, and execution hosts, and another designated person may perform acceptance, but responsibility changes require an explicit handoff. A handoff uses a stage checkpoint or complete pause savepoint and carries the current state, effective rule set, unresolved risks, and recovery entry. At any moment, only one execution host may hold the execution lease for the same repository workspace or execution branch, preventing concurrent changes from undermining recovery and auditability. The first team collaboration version does not add group chat, general documentation, or real-time collaborative editing.

## 中文

# 每个目标只有一名负责人并通过完整恢复位置交接

每个工作目标始终只有一名当前负责人，对目标边界、计划确认、授权、异常处理和进入验收负责。执行可以跨成员、工具和执行端，验收也可以由其他指定人员完成，但责任变化必须形成明确交接。交接依赖阶段检查点或完整的暂停保存点，携带当前状态、生效规则集、未解决风险和恢复入口；同一仓库工作区或执行分支在一个时点只允许一个执行端持有执行租约，避免并发修改破坏恢复与审计。团队协同第一版不增加群聊、通用文档或多人实时编辑。
