# Only Structured Rules Can Be Declared Automatically Enforced

The first version limits team rules to structured rules with an explicit scope and machine-evaluable conditions. These include tools and environments, resource limits, restricted paths and commands, approval conditions, required checks, acceptance evidence, and acceptance roles. Each rule must also record whether the current adapter can block before execution, detect after execution, collect evidence, request human confirmation, or does not support it. Structure does not guarantee prevention. Natural-language rules in repositories and documents may enter the effective rule set and be passed to AI, but they must be marked as guidance. The product must not claim they were enforced automatically unless they become checkable conditions or receive human confirmation.

## 中文

# 只有结构化规则才能被声明为自动执行

第一版团队规则限定为具有明确适用范围和机器可判断条件的结构化规则，包括工具与环境、资源限制、受限路径和命令、批准条件、必需检查、验收证据与验收角色。每条规则还必须记录当前适配器能够执行前阻止、执行后检测、收集证据、请求人工确认还是不支持。结构化不代表一定能够阻止。仓库和文档中的自然语言规则可以进入生效规则集并传递给 AI，但必须标记为指导性规则；除非转换为可检查条件或得到人工确认，产品不得声称它已被自动执行。
