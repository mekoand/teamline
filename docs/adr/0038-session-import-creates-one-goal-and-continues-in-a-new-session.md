# Each Session Import Creates One Goal and Continues in a New Session

Each V2 import creates one goal rather than a batch of goals or projects. A user may select one or more Codex sessions that serve the same outcome and give the goal a name. The same source session cannot belong to multiple goals. Import confirmation authorizes Teamline to read the selected local sessions and use Codex to organize a goal summary, key nodes, current state, and result references, but it does not authorize continued execution. Teamline saves the organized result and source references without copying the complete conversation.

The original sessions remain in Codex as historical sources. Teamline uses their update time to suggest reorganization rather than maintaining continuous bidirectional synchronization. When the user chooses to continue the goal, Teamline creates a new consolidated session instead of making several original sessions simultaneous execution entries.

## 中文

# 会话导入每次只创建一个目标并从新会话继续

V2 每次导入只创建一个目标，不批量创建目标或项目；用户可以选择一个或多个服务于同一结果的 Codex 会话并为目标命名。同一来源会话不会重复归入多个目标。导入确认允许 Teamline 读取所选本地会话并使用 Codex 整理目标摘要、关键节点、当前状态和成果引用，但不授权继续执行；Teamline 保存整理结果和来源引用，不复制完整会话。

原会话继续留在 Codex 中作为历史来源。Teamline 通过来源会话的更新时间提示用户重新整理，不持续双向同步；用户决定继续目标时，Teamline 创建新的整合会话，而不尝试让多个原会话同时成为后续执行入口。
