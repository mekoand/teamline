# The Team Console Coordinates AI Coding Work Only

The paid team product stores the goal state, execution resources, authorization approvals, exception handling, and acceptance evidence needed to advance AI coding work. It references source information in GitHub, Linear, Jira, Notion, or Slack through integrations. It will not expand into a general chat, documentation, requirements management, or code hosting platform because rebuilding mature collaboration tools would blur the product boundary of the work control layer.

---

## 中文

# 团队控制台只协调 AI 编码工作

付费团队产品保存推进 AI 编码工作所需的目标状态、执行资源、授权审批、异常处理和验收证据，并通过集成引用 GitHub、Linear、Jira、Notion 或 Slack 中的原始信息。它不扩展成通用聊天、文档、需求管理或代码托管平台，以免重建成熟协作工具并模糊工作控制层的产品边界。
