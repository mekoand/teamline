# Incompatible Rule Conflicts Require Human Resolution

The console combines rules that can be satisfied together and applies the stricter condition when constraints can be compared objectively. If rules truly conflict and there is no objectively stricter result, the console must not choose silently based on source priority, update time, or model judgment. The work controller resolves the conflict before plan confirmation. Any decision that relaxes a published team rule must become a scoped and time-limited exception with a reason and approval record. AI cannot approve it by itself.

## 中文

# 无法兼容的规则冲突必须由人处理

控制台会合并能够同时满足的规则，并在约束可以明确比较时采用更严格的一项。若规则真正矛盾且不存在客观的更严格结果，控制台不得使用来源优先、更新时间或模型判断静默取舍，而是在计划确认前交给工作控制者处理。任何放宽已发布团队规则的处理结果都必须形成有范围、有期限、有原因和批准记录的规则例外，AI 不能自行批准。
