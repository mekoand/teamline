# 首个付费 MVP 只证明一条受控委托闭环

首个付费 MVP 复用已经在单仓库、单工具个人闭环中验证的本地执行内核。负责人从仓库和外部需求引用创建工作委托，控制层生成计划并解析生效规则集；负责人确认并授权后，本地执行端启动现有 AI 编码工具。控制台持续记录运行状态与检查点，支持暂停、恢复和交接，在必需检查与证据齐备后进入待验收。运行总览和执行地图只是这条闭环的不同视图，额度、预算和工具可用性作为资源约束参与执行决策。

付费试点只接入一个代码托管平台、通用本地命令入口，以及由试点团队决定的一种深度 AI 工具适配。它不包含自动跨工具切换、通用文档、聊天、双向同步、自由画布、托管 Agent 或任意自然语言规则验证。
