# The Formal Technology Stack Follows Capability Spikes

The recovery-logic prototype may temporarily use an existing runtime such as Bun, but it does not decide the technology stack for personal kernel v0. Before the formal specification is frozen, Teamline must first test candidate Codex integration surfaces and run small practical checks around Apple Silicon macOS process-tree pause, termination and fencing; Git worktrees and content recovery; crash persistence; local web security; installation and upgrades; and future host adapters. Those results determine the stack rather than inferring it from a logic prototype or the frontend shape of a future online control plane.

## 中文

# 正式技术栈在能力验证后决定

恢复逻辑原型可以临时使用 Bun 等现有运行时，但不形成个人内核 v0 的技术栈决定。正式规格冻结前必须先验证 Codex 候选接入面，并围绕 Apple Silicon macOS 的进程树暂停、终止与围栏，Git worktree 与内容恢复，崩溃持久化，本地网页安全，安装升级和未来主机适配进行小型实测；技术栈依据这些结果选择，而不是从逻辑原型或未来在线控制面的前端形态反推。
