# Tools and Budgets Belong in the Goal Plan

When a work goal plan is confirmed, it also defines a resource plan: allowed tools, models, provider references and execution environments; preferred and fallback order; budgets, quota, and run time; and changes that require renewed approval. Personal kernel v0 only validates constraints for one goal. It records Codex, the identifiable model, a maximum run time, and optional usage or cost alert thresholds. Local run time can stop execution at the limit. Tokens, cost, and quota may trigger an authorized action only when their data is current, attributable, and meets the rule requirements; otherwise they are explicitly advisory. Personal kernel v0 does not integrate CC Switch or provide subscription switching, cross-tool allocation, or a resource overview. Personal Alpha then validates resource overview and allocation across parallel goals and multiple providers. The paid team MVP later adds shared budget allocation, reservation, and centralized audit. The product neither resells model quota nor centrally holds vendor accounts.

In Personal Alpha, priority, execution pace, and “run when quota is available” are user-editable run preferences rather than part of the AI plan version. The switch is off by default. Turning it on authorizes Teamline to use a fresh, non-conflicting Codex account availability window to start one bounded run. This signal only indicates whether the account is currently suitable for execution; it cannot attribute aggregate account cost or usage to a goal.

## 中文

# 工具与预算进入执行计划而不只是被监控

每个工作目标在计划确认时同时确定资源方案，包括允许的工具、模型、Provider 引用与执行环境，首选和备用顺序，预算、额度与运行时间，以及需要重新批准的变化。个人内核 v0 只验证单个目标约束：记录 Codex、可识别的模型、最长运行时间和可选用量或费用提醒阈值；本地运行时间可以到点暂停，Token、费用和额度只有在实时、可归因并达到规则要求时才能触发已授权动作，否则明确标为仅提醒。个人内核 v0 不接 CC Switch，不做订阅切换、跨工具分配或资源总览。个人 Alpha 再验证多个并行目标与多个 Provider 的资源总览和分配，团队付费 MVP 才增加共享预算的分配、预留与集中审计；产品不代购或转售模型额度，也不集中托管供应商账号。

个人 Alpha 中，优先级、执行节奏和“额度充足时运行”是用户可随时修改的运行偏好，不进入 AI 计划版本。开关默认关闭，用户主动打开即授权 Teamline 使用新鲜且无冲突的 Codex 账户额度窗口触发一轮有上限的执行；该信号只用于判断账户当前是否适合运行，不能据此把账户聚合成本或用量归入某个目标。
