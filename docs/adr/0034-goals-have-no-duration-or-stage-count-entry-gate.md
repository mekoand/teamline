# Goals Have No Duration or Stage-Count Entry Requirement

Any AI work with a clear boundary, expected result, scope of impact, and acceptance method can be created as a work goal. Short work may use a single-stage plan, while longer work naturally becomes several independently verifiable execution stages. Teamline neither asks users to estimate duration before starting nor blocks goal creation based on stage count. “At least two hours or two execution stages” is only a complexity tier recorded before pilots so the product's value can be evaluated separately for short and long-running work. It does not appear in the product creation flow.

## 中文

# 工作目标不设置时长或阶段数门槛

任何具有明确边界、预期结果、影响范围和验收方式的 AI 工作都可以创建为工作目标。短工作可以使用单阶段计划，长程工作自然形成多个可独立验证的执行阶段；Teamline 不要求用户在开始前估算时长，也不以阶段数量阻止创建。“预计至少两小时或两个执行阶段”只作为试点中预先登记的复杂度分层，用于分别判断短工作与长程工作的实际价值，不进入产品创建流程。
